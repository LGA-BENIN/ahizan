Un slug est la version simplifiée et lisible du nom d'une page ou d'un produit, utilisée principalement dans son adresse web (URL).

Exemple pour Ahizan

Nom du produit :

Samsung Galaxy A16 256 Go – 8 Go RAM – Noir

Le slug sera :

samsung-galaxy-a16-256-go-8-go-ram-noir

L'adresse pourrait alors ressembler à :

ahizan.com/samsung-galaxy-a16-256-go-8-go-ram-noir

Comment un slug est construit ?

En général :

tout en minuscules ;
les espaces deviennent des tirets - ;
les accents sont supprimés ;
les caractères spéciaux sont supprimés ;
on évite les mots inutiles ;
il doit rester unique.

Par exemple :

Nom :

Huile Dinor 1 L – Bidon

Slug :

huile-dinor-1-l-bidon

Pourquoi c'est important pour Ahizan ?

Le slug sert notamment à :

identifier la page du produit ;
rendre l'URL compréhensible ;
faciliter le référencement naturel (SEO) ;
permettre aux moteurs de recherche de mieux comprendre le contenu ;
créer des liens propres et faciles à partager.

Attention : le slug n'est pas le SKU.

SKU → identifie une variante pour la gestion commerciale.
Slug → identifie généralement la page du produit sur le site.

Exemple :

Produit : Samsung Galaxy A16
Slug : samsung-galaxy-a16
SKU variante : SAM-A16-BK-256

Pour Ahizan, je recommande même que le slug soit généré automatiquement par Ahizan, plutôt que demandé au vendeur.
